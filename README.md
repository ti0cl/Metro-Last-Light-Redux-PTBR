## 📖 Sobre o projeto

Este repositório acompanha o desenvolvimento de uma tradução não oficial de **Metro: Last Light Redux** para **português brasileiro (PT-BR)**.

O objetivo é traduzir o conteúdo textual do jogo, preservando o contexto narrativo, a terminologia e os elementos técnicos necessários para o funcionamento correto dos arquivos.

"Mas essa tradução já existe." Talvez você pense isso. Sim, já existe, mas eu decidi criar a minha versão. É uma forma de manter viva a lembrança dos ótimos momentos que passei como membro, moderador e supermoderador do antigo GameVicio (2003–2011). 🙃

> **Aviso:** projeto em andamento. Ainda não há uma versão pública deste projeto finalizada ou validada para instalação.

## 🛠️ Fluxo de trabalho

1. **Extração e catalogação:** identificar entradas textuais e seus respectivos identificadores.
2. **Tradução:** produzir versões em português brasileiro respeitando o contexto do jogo.
3. **Validação técnica:** conferir identificadores, marcadores, placeholders e estrutura dos arquivos.
4. **Revisão linguística:** verificar fluidez, coerência e ausência de trechos em inglês não intencionais.
5. **Integração e testes:** verificar os arquivos traduzidos no ambiente do jogo antes de qualquer lançamento.

O trabalho utiliza automação e agentes de IA para auxiliar na produção de ferramentas, na tradução e na revisão. **Os resultados gerados por IA não devem ser considerados aprovados sem validação.**

## 🤝 Créditos e transparência

Projeto independente de tradução PT-BR, com apoio de ferramentas de automação n8n e inteligência artificial.

Inteligências Artificiais usadas no projeto: ChatGPT Descktop + Work + Codex, Gemini Deskto, Claude e OpenCode. Estes são os agentes construtores que geraram os códigos json, JavaScripts, Python, html, php, md e txt, além de instruções para os agenstes de produção e análise de reatórios.

Modelos usados no fluxo de trabalho e produção de lotes: Gemini 3.5, Gemine 3.8 e TranslateGemma são os agentes tradutores e revisores, NVidia Nemotron e DeepSeek são os responsáveis pela manutenção e checagem de falhas para manter o sistema funcional e livre de erros.

Créditos adicionais de colaboradores e ferramentas serão documentados conforme existência de participação confirmada.
